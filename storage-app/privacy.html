Privacy and Google data use

Trading Robot Storage is a private archive utility controlled by its operator. This page describes its intended Google Drive integration.

Access and purpose

The application requests only https://www.googleapis.com/auth/drive.file. It creates and reads archive objects in a dedicated folder and uses file identity and restored content to verify backups. It does not request unrestricted access to Google Drive. The storage executor does not delete remote files.

Storage and disclosure

Archive content is stored in the operator’s Google Drive and on the operator’s server. OAuth client credentials and refresh tokens are held in protected local or server secret files, outside source control and ordinary application logs. Credentials are not included in command-line arguments or user-facing reports.

The storage integration does not sell Google user data, use it for advertising, or send Drive archive contents to language models. Google processes the uploaded files as the cloud storage provider. The operator controls the server that performs archive transfers.

Control

The operator can revoke this application in Google Account permissions. Revocation stops future authorized access; it does not itself remove previously uploaded files. The operator manages retained files in Google Drive. The support contact is shown on the Google OAuth consent screen.

Use of information received from Google APIs follows the Google API Services User Data Policy, including Limited Use requirements.
