Trading Robot Storage

A private archive utility for its operator. It copies selected local archive files to a dedicated Google Drive folder, reads the uploaded object back, and compares the restored file with its local SHA-256 hash.

The application requests the Google Drive drive.file permission. Access is limited to files created by this application or explicitly opened with it. It does not request access to the operator’s entire Drive.

This OAuth application is used for deterministic storage operations. It does not provide trading services or make financial transactions.
